# Rhythm Lab

目で見て、聴いて、触ってリズムを学べる16ステップ式ビートマシンです。

## 現在の機能

- 8種類のドラム／パーカッション音
- 16ステップシーケンサー
- 再生・停止・クリア
- BPM 50〜180
- スウィング調整
- 音量調整
- 再生位置と「1 e & a」の視覚表示
- 8ビート、4つ打ち、ヒップホップ、ファンク、シャッフル、ラテンのプリセット
- 各リズムの簡単な学習解説
- スマートフォン・タブレット対応
- Web Audio APIによるブラウザ内音声生成

## 起動方法

`index.html` をブラウザで開くだけで動作します。初回は再生ボタンまたはステップをタップすると音声が有効になります。

## ファイル構成

- `index.html`：画面構造
- `style.css`：デザインとレスポンシブ表示
- `app.js`：シーケンサー、音声生成、プリセット
